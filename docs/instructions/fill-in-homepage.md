# Fill In the Homepage

Each section of the [homepage](../index.md) pulls its text from a small file that anyone in the group can edit directly on GitHub — no setup needed. Click an **Edit** link below, change the text, and choose **Commit changes**. The site rebuilds and republishes automatically within a few minutes.

Each file starts with a hidden comment explaining what to write. The comment never appears on the website.

## Ground rules

- Text marked *Draft — pending group review* is unreviewed draft. Replace it with what the group has actually decided, or delete it.
- Don't state a commitment (data governance, source permissions, contact addresses) until the group has made it.
- Plain text and simple Markdown work fine: `**bold**`, `*italic*`, and blank lines between paragraphs.
